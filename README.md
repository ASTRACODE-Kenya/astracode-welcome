# 🎓 AstraCode Web3: Onboarding Sandbox

Welcome! This is your zero-risk environment to learn the open-source GitHub workflow.

##  Your First Mission
1. Go to the **Issues** tab and comment `.take` on the Onboarding issue.
2. Click **Fork** at the top right of this page.
3. Clone your fork locally and create a new branch.
4. Add your details to `CONTRIBUTORS.md`.
5. Push to your fork and submit a Pull Request back to this repository!
